# 客户行为与消费习惯分析

基于 RFM 模型的客户分群与高价值客户识别项目。

## 📊 项目简介

本项目使用 **RFM 模型**（最近消费时间、购买频率、消费金额）对 5 万条客户行为数据进行深度分析，完成客户分群、高价值客户识别，并生成业务策略建议。

## 📁 数据集

- **客户行为与消费习惯的数据集.csv**（50,000 行，25 列）
- 包含人口统计、网站交互、消费记录、客户服务、营销互动等多维度字段

## 🔍 分析流程

1. **数据清洗**
   - 剔除缺失率超过 20% 的样本（保留 49,988 条）
   - 检查重复值（无重复）
2. **RFM 评分与客户分群**
   - 对 R、F、M 三项分别进行五分位打分（1~5 分）
   - 根据得分组合将客户划分为 **8 类**：
     - 顶级高价值客户、核心高价值客户、潜力唤醒客户、潜力成长客户、
     - 新客户、流失风险客户、沉睡客户、一般客户
3. **高价值客户识别**
   - 方法 1：RFM 总分前 20%
   - 方法 2：特定分群筛选（顶级/核心/潜力唤醒）
   - 对比高价值客户与普通客户在关键行为指标上的差异
4. **可视化分析**
   - RFM 分数分布柱状图
   - 客户分群占比饼图 / 条形图
   - 高价值客户特征雷达图
5. **业务建议输出**
   - 针对每类客户群提出差异化营销策略
   - 导出分群汇总统计表及完整 RFM 结果

## 🛠️ 使用技术

- Python 3
- pandas, numpy, matplotlib, seaborn
- Jupyter Notebook

## 📂 文件说明

- `客户行为与消费习惯的数据集.csv` – 原始数据
- `客户行为与消费习惯分析.ipynb` – 完整分析代码
- `rfm_analysis_full.csv` – 包含 RFM 评分和分群结果的完整数据
- `customer_segment_summary.csv` – 各客户群汇总统计表
- `high_value_customers2.csv` – 高价值客户列表（RFM 总分前 20%）
